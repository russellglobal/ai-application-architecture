## 📖 这是什么

一门让你系统性学习 **AI 应用架构** 的开源课程，一门让你"华丽转身"，深度学习AI应用的课程。基于三个真实产品案例（锦囊、拓令通、明镜），覆盖从 Agent 设计到生产运维的完整知识体系。

**与其他课程不同**：不教"怎么做"，教"架构思维"，教"什么时候该做、什么时候不该做、为什么"。

## 🎯 适合谁

- ✅ AI开发者，希望系统性学习AI架构知识
- ✅ 传统程序员/架构师（3-10年），希望转型AI开发
- ✅ 技术决策者，需要评估 AI 系统方案
- ✅ 技术OPC：希望深度研究AI应用
- ✅ 有一定技术背景，希望用对、用好AI解决实际问题的上下游专家（产品经理、FDE、前端、测试等专家）

**不适合**：零基础小白、纯管理层（无代码实战）、团队培训（可线下咨询）
