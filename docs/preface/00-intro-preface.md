# 序言：为什么做这套课程

## 关于作者

我是Russell，原华为18级架构师、阿里云P7解决方案架构师，独立落地了多个AI产品。

## 我为什么做这套课程

核心原因就一个：我发现市场严重缺少**"AI应用架构"**的概念，大大降低了大家使用AI的效率，而我恰好有相关的背景。

我们使用AI做项目，经常遇到各种问题，如果没有架构思维，往往掉入"就问题解决问题"的陷阱，而不是一次性系统地解决。

我们使用AI开发项目，如果没有架构思维，就不能一眼看到整体的路径，走一步看一步，给后续运维迭代留大坑。

## 这套课程适合谁

- AI开发者，希望系统性学习AI架构知识
- 传统程序员/架构师（3-10年），希望转型AI开发
- 企业研发团队：AI转型培训（可线下咨询）
- 希望深度研究VibeCoding，有一定技术背景的OPC
- 有一定技术背景，希望用对、用好AI解决实际问题的上下游专家（产品经理、FDE、前端、测试等专家）

## 这套课程不适合谁

- **高管**：本课程没有AI转型和AI战略内容（可定制）
- **小白**：本课程要求有一定技术背景
- **安全**：本课程不将安全作为主要方向

## 贯穿课程的三个真实产品

这门课不讲空洞理论，所有知识点都用我独立开发的三个真实产品作为案例：

| 产品 | 定位 | 贯穿的课程模块 |
|------|------|----------------|
| **锦囊 StratSapien** | AI 商业分析 SaaS（付费产品，已有用户） | Agent 编排、SaaS 架构、成本管控、0→1 全流程 |
| **拓令通 TokSlash** | MCP 结构化文档编辑系统（Token 节省 94.7%） | MCP 实战、Tool 设计、Prompt 工程化、本地工具架构 |
| **明镜 SapienMira** | Claude Code 行为分析系统（模式检测 + 评测） | 分层架构、可观测性、评测体系、数据一致性 |

每个案例不只讲"做了什么"，更讲**"为什么这么做"、"踩过什么坑"、"如果重来会怎么做"**。

## 这门课和其他 AI 课程有什么不同？

| | 工具教程 | 论文解读 | Demo 实战 | **这门课** |
|---|---|---|---|---|
| **教你** | 用工具 | 读理论 | 搭 Demo | **做决策** |
| **典型内容** | "LangChain 入门" | "ReAct 原理解析" | "30 分钟搭 RAG" | "什么时候该用 Agent，什么时候不该" |
| **你的收获** | 会用一个框架 | 理解一篇论文 | 能跑通一个流程 | **能做架构决策** |
| **问题** | 框架换了就过时 | 不知道怎么落地 | 不知道怎么上线 | 能应对技术变化 |

**一句话总结：其他课程教你"怎么做"，这门课教你"什么时候该做、什么时候不该做、为什么"。**
