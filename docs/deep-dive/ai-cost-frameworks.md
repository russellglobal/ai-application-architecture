# AI 成本分析框架汇总

> 本文档汇总多个 AI 成本分析框架，作为课程第 13 讲（成本优化与容灾恢复）的补充参考。
> 不同框架从不同视角切入，读者按需选读。

---

## 1. Russell: 企业级AI 全链路成本架构（企业全链路视角）

从上层组织到底层基础设施，逐层拆解 AI 系统的全链路成本：

| 层级 | 成本内容 |
|------|---------|
| **组织层** | 团队人力、培训、跨部门协作、项目管理及合规治理费用 |
| **应用层** | 业务集成、前端开发、用户体验优化及定制化交付成本 |
| **平台层** | MLOps 工具、模型部署平台、监控与运维系统的投入 |
| **模型层** | 模型设计、预训练、微调、蒸馏及压缩成本 |
| **数据层** | 数据采集、清洗、标注、存储及管理成本 |
| **基础设施层** | 算力（GPU/CPU）、存储、网络等硬件及云服务费用 |

**适用视角**：全面盘点 AI 系统成本构成，适合做预算规划和成本归因。

## 2. SyncSoft 七层 LLM FinOps 蓝图（技术降本视角）

来源：SyncSoft AI（2026.04）。聚焦**推理成本治理**，七层分别是：

1. 模型分层（70% 请求路由到经济型模型）
2. 提示缓存
3. 语义缓存
4. 批处理推理
5. 上下文压缩
6. 输出纪律
7. 可观测性与归因

宣称可在 90 天内帮企业削减 60–73% 推理成本。

**适用视角**：纯技术降本，适合架构师做推理层成本优化。与课程第 11 讲（LLM 运行时治理）的内容高度重合。

---

## 3. EY Agentic AI 七层成本框架（企业治理视角）

来源：安永（EY）Agentic AI 经济分析。覆盖从技术到组织的完整成本：

1. Tokens and API Calls（代币与 API 调用）
2. Subscriptions and Licenses（订阅与许可）
3. Platform Infrastructure（平台基础设施）
4. Governance Burden（治理负担）
5. Organizational Change（组织变革）
6. Expected Failure and Recovery（预期故障与恢复）
7. Agent Regulations（智能体监管）

**适用视角**：企业治理 + 组织变革，适合 CTO/VP 级别做 AI 投资决策。"Organizational Change" 和 "Governance Burden" 是技术团队容易忽略的隐性成本。

---

## 4. Rework AI TCO 七要素（采购视角）

来源：Rework（2026.02）。将 AI 总拥有成本（TCO）拆为七个组件：

1. 软件许可
2. 计算资源
3. 数据基础设施
4. 人才成本
5. 集成与定制
6. 培训与变革管理
7. 治理与合规

核心观点：第一个可见成本之外的**隐藏成本往往带来 10.7 倍的预算乘数**。

**适用视角**：企业采购视角，适合做 AI 项目预算和 TCO 评估。"10.7x 隐藏成本乘数"是一个有冲击力的数据点。
